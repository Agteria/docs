## Prerequisites

- Docker
- A GCP project with the required APIs enabled
- A PubMed API key (optional — raises rate limits from 3 to 10 req/s)

## Local development

The dev stack runs through Docker Compose.

<Steps>
  <Step title="Start the dev container">
    ```bash
    docker-compose up dev
    ```
  </Step>
  <Step title="Run unit tests">
    ```bash
    docker-compose run test
    ```
  </Step>
  <Step title="Run integration tests">
    ```bash
    docker-compose run test-integration
    ```
  </Step>
</Steps>
