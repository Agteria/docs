Sage is a PubMed research-paper ingestion pipeline running on Google Cloud Platform. It discovers papers via configurable search queries, retrieves metadata and full text when available, deduplicates by DOI/PMID, and stores content to Cloud Storage with metadata in BigQuery.

## What it does

Sage runs as a scheduled Cloud Run Job with support for incremental updates and historical backfills. Search queries are configured in Firestore, so adding a new research topic doesn't require a code change.
