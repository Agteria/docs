## Ground rules for these docs

- **One fact, one place.** Shared practices live in How We Work; project pages link to them and only document deviations.
- **Every project follows the same template.** See [documenting a project](/projects/overview) before adding one.
- **If you learned something the hard way, write it down.** The "Decisions & gotchas" page of each project exists for exactly this.
